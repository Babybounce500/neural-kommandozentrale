The "Erprobter Dev Dude" Filter — Quality Over Quantity
SAME PRINCIPLE — DIFFERENT VERIFICATION
DUDE BANK: Social Vouching + 1000€ + Rulebook = GENITUS: Portfolio + PR + Rulebook
In DUDE BANK, a new Dude must be vouched for, pay their Geschäftsguthaben, and sign the Rulebook. In GENITUS DUDE FACTORY: a new Dev Dude must show a GitHub portfolio (vouching equivalent), submit one accepted pull request (Geschäftsguthaben equivalent — skin in the game), and sign the Contribution Agreement & Code of Conduct (Rulebook).

No anonymous contributors. No Sybil attacks. No speculative code without review. The 2/3 Guardian Dude review gate means every line of production code was approved by two independent Senior Dev Dudes before deploy.
