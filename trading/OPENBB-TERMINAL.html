1. Python Installation

pip install openbb openbb-yfinance openbb-api

Installs the OpenBB Platform core + yfinance provider (free, no key needed) + the local REST API server.

2. Start the API Server

python -c "import openbb_api; openbb_api.main()"

Or alternatively:

openbb-api --host 127.0.0.1 --port 6900

Server starts at http://localhost:6900 — the interactive Swagger docs are at /docs.

3. Available Free Endpoints (yfinance provider)

GET /api/v1/equity/price/historical — OHLCV historisch
GET /api/v1/equity/price/quote — Realtime Quote
GET /api/v1/crypto/price/historical — Crypto OHLCV
GET /api/v1/equity/fundamental/income — Income Statement
GET /api/v1/equity/fundamental/balance — Balance Sheet
GET /api/v1/equity/news — Company News
GET /api/v1/economy/fred_series — FRED (requires free FRED key)

4. FRED API Key (für Makro-Daten)

obb.account.login(pat="your_personal_access_token")

Kostenlos registrieren auf fred.stlouisfed.org/docs/api/api_key.html — dann im FRED-Tab eintragen.

5. Connection Test

Klicke oben rechts auf 🔌 Connect — der Status-Indikator wird grün wenn der Server läuft.
